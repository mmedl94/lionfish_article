# Interactively Visualizing Multivariate Market Segmentation Using the R Package Lionfish

This repository contains all scripts and data that was used to produce the article "Interactively Visualizing Multivariate Market Segmentation Using the R Package Lionfish" submitted to the Austrian Journal of Statistics.

The three most noteworthy elements of this repository are

1.  the scripts folder, which holds all scripts required to reproduce all results,

2.  the saves folder, which holds the all the lionfish snapshots of the displayed plots,

3.  and the manuscript.tex file, which is the LaTeX file used to generate the article.

For a step-by-step guide on how to reproduce the results shown in the article please follow [this link](https://mmedl94.github.io/lionfish/articles/Market-segementation.html).
